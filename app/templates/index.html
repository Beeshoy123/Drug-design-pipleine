02
Invention & verification
REINVENT4 generation · AiZynthFinder buildability

REINVENT4 invents brand-new molecules, each scored against the reference pattern — 60% pattern match, 25% drug-likeness (QED), 15% Lipinski check. Then the retrosynthesis checker verifies the top candidates are actually makeable.

invention takes ~1 minute; buildability checks stream in one by one.
03
The full pipeline, one click
Invent → score → verify → ranked report

Runs everything on the reference molecule and keeps only the winners — makeable and best-scoring — as a ranked table you can download as CSV. About 1–2 minutes on this machine.

want different candidates? rerun, or go back and pick another reference.
