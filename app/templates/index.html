Step 3 · Generate

AI Chef — invent molecules like the reference

REINVENT4 invents brand-new molecules, then each one is scored against the reference pattern above: 60% pattern match, 25% drug-likeness (QED), 15% Lipinski check. Runs on CPU — about 10 seconds.

Step 5 · Full Pipeline Report

One-click: invent → score → check buildability → rank

Runs every step on the reference molecule: REINVENT4 invents 100 candidates, the judge ranks them, the shopping checker verifies the top ones are actually makeable, and the final report keeps only the winners — makeable + best-scoring — as a ranked table you can download as CSV. Takes about 1–2 minutes on this little machine.
